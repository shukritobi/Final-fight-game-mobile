# Neon Brawl: Streets of KL

A mobile-first browser beat 'em up inspired by classic arcade brawlers, with original characters, stages and combat.

## Features

- Responsive HTML5 Canvas game
- Mobile joystick and four-button arcade controls
- Desktop keyboard support
- Punch, kick, jump and energy-based special attacks
- Combo scoring, hit sparks, screen shake and generated arcade sound effects
- Three original stages with parallax scenery
- Multiple enemy archetypes, weapons, pickups and three boss fights
- Offline-capable PWA shell
- No build step and no external game engine

## Controls

- Move: touch joystick, WASD or arrow keys
- Punch: J
- Kick: K
- Jump: L
- Special: I
- Pause: P or Escape

## Run locally

Open `index.html`, or serve the folder with any static server.

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
